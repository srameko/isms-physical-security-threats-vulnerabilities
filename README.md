# Threat Intelligence, zranitelnosti a fyzická bezpečnost

Prezentace pro kurz Czechitas Digital Academy: Specialistka informační bezpečnosti. Pokrývá Threat Intelligence (ISO 27001 — opatření 5.7), management technických zranitelností / Vulnerability Management (opatření 8.8) a fyzickou bezpečnost (opatření 7.1–7.7): pojmy a zdroje Threat Intelligence, životní cyklus Vulnerability Managementu, CVE/CVSS, skenovací nástroje, fyzické perimetry, fyzický vstup, monitoring a clear desk/clear screen politiku.
